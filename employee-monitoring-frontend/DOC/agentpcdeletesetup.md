Task Manager: Sabse pehle Task Manager (Ctrl+Shift+Esc) khol kar insightful-agent.exe ko End Task karein.


Registry Delete:
Win + R dabayein, regedit likhein.

Iss location par jayein: HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run

Wahan insightful-agent naam ki entry ko Right-click karke Delete kar dein.

Program Folder Delete:
File Explorer mein %LOCALAPPDATA%\Programs likh kar enter maarein.

Yahan insightful-agent naam ka folder delete kar dein.

Data Folder Delete:
File Explorer mein %APPDATA% likh kar enter maarein.

Wahan bhi insightful-agent folder ko delete karein (isme purane logs aur settings hoti hain).

Startup Folder Check:
Win + R mein shell:startup likhein. Agar wahan koi shortcut dikhe toh use delete kar dein.

Summary: Sirf file delete karne se nahi hoga, Registry entry aur AppData folders ko upar diye gaye steps ke hisaab se saaf karna padega tabhi ye rukega.
